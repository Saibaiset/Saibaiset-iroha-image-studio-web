# IROHA 画像編集 Chromebook版

Chromeブラウザーで動く、静的な画像編集Webアプリです。サーバー側の処理や外部ライブラリを使わず、選んだ画像はブラウザー内で処理します。

## GitHub Pagesへの公開

1. GitHubで新しいリポジトリを作ります。GitHub FreeでPagesを使う場合は、公開リポジトリにしてください。このフォルダーの**中身**（`.github` を含む）をリポジトリのルートへアップロードします。
2. リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **GitHub Actions** にします。
3. `main` または `master` ブランチへ変更を送ると、ActionsがWebアプリを公開します。初回実行時は **Actions** タブで公開処理の完了を確認します。
4. Pagesに表示される `https://アカウント名.github.io/リポジトリ名/` をChromebookのChromeで開き、メニューからインストールまたはホーム画面へ追加します。

独自ドメインを購入する必要はありません。GitHub Pagesの無料URLを利用できます。無料プランで公開する場合、リポジトリ内のソースコードは公開状態になります。

## オフライン利用

一度公開URLを開くとアプリ本体をキャッシュし、その後はオフラインでも起動できます。初回の読み込みとインストールにはインターネット接続が必要です。

## 画像処理

画像は選択した端末上のブラウザー内で読み込み、処理して書き出します。画像ファイルを外部へアップロードしません。画像サイズが大きい場合は、Chromebookのメモリー容量により処理に時間がかかることがあります。

## 対応する編集

- 画像を開く、ドラッグ＆ドロップ、PNG / JPEG / WebP書き出し
- 露出、傾き、明るさ、コントラスト、彩度、色温度、色かぶり、トーン、ハイライト、シャドー、白・黒ポイント、シャープ、ビネット、粒状感
- 補正プリセット、16種類の色フィルター、12種類のフィルム風ルック
- 比率指定と8方向ハンドルによる切り抜き、回転、反転
- 文字、塗りつぶし図形、手描き線、領域モザイク / ぼかし
- 戻す、最初の状態に戻す、表示倍率変更、ライト / ダーク / システムテーマ

フィルム風ルックは、フィルムやカメラの色調から着想したIROHA独自の表現です。各メーカーの公式シミュレーションを再現したものではありません。
